# Arturs Taskmanager V8.0 — Release Candidate

## Scope

V8 introduces the premium enterprise desktop presentation while preserving the existing task-management workflows and data model.

## Included

- V8 premium application shell and navigation
- Task workspace with detail inspector
- Kanban, Eisenhower and Planning presentation layers
- Responsive desktop behavior
- Protected drag-and-drop persistence
- Startup undo availability based on the latest backup
- Windows PyInstaller packaging for all V8 modules
- Windows EXE startup smoke test in CI

## Release gate

The release candidate is considered releasable only after the Windows GitHub Actions workflow completes successfully, including the complete test suite, PyInstaller build, V8 module verification, EXE startup smoke test and artifact creation.
