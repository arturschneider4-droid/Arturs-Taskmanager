# Arturs Taskmanager V10.0

## Release-Artefakte

- `ArtursTaskmanager-V10.0-Windows.zip`
- `SHA256SUMS-V10.0.txt`
- enthaltene Anwendung: `ArtursTaskmanager.exe`

## Verifikation

- vollständige automatisierte Testsuite
- dreifacher Stabilitätslauf ohne Fehler
- E2E-Kernworkflow einschließlich Backup/Wiederherstellung
- Start- und Workflow-Smoke-Test unter Windows
- Startprüfung mit 100 %, 125 % und 150 % Skalierung
- visuelle Referenzen aller produktiven Routen in drei Fenstergrößen
- SHA-256-Prüfsumme des finalen ZIP

## Daten und Upgrade

Vor der V10-Migration wird automatisch ein Datenbankbackup erstellt. Die Anwendung bleibt offline; Aufgabendaten werden ausschließlich lokal unter `%USERPROFILE%\TaskManager` gespeichert.

## Bekannte Einschränkung

Die Anwendung ist für einen lokalen Einzelbenutzer ausgelegt. Cloud-Synchronisation und Mehrbenutzerbetrieb gehören nicht zum Umfang von V10.0.
